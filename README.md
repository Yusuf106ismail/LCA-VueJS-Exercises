# Cooking Masterclass - Interactive Checkout Prototype

A modern, highly responsive Vue 3 checkout simulation built for the **Cooking Masterclass** platform. This tool allows product and design teams to interactively test course browsing, dynamic cart updates, quantity manipulations, and real-time checkout tax logic entirely on the client side.

---

## ✨ Features Built & Delivered

* **Interactive Course Catalogue:** Showcases rich metadata grids including pricing, difficulty tags, assigned chefs, and durations.
* **Smart "Sold Out" Controls:** Visually locks down exhausted courses, altering UI layout elements and disabling click triggers cleanly.
* **Live Price Summary Aggregations:** Computes immediate subtotal increments, handles a local 15% VAT calculation engine, and yields a precision grand total.
* **Active Coupon Management:** Integrated a promo field allowing users to apply code `SAVE10` for an immediate 10% discount off the baseline subtotal.
* **Persistent Local Storage Buffer:** Saves active shopping basket layouts to the browser, ensuring data survives page updates or reloads.
* **Responsive Layout Architecture:** Adaptive two-column monitor viewport layout that smoothly collapses into a single-stack layout for mobile viewports.
